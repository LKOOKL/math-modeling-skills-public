# 用户国赛模板：固定骨架与局部改写

## 依据与适用范围

用户已指定以下 TeXstudio 模板作为数学建模论文写作的大框架，并要求在此基础上融合写作经验、支持小修，以及每问模型至少展示伪代码或流程图之一。

- 使用随附的 [TeX 模板](../assets/user-national-template/template_数学建模国赛.tex)及其 [TeXstudio 元数据](../assets/user-national-template/template_数学建模国赛.json)核对结构和样式。
- 文件校验值见[分发清单](../../../docs/source-manifest.json)。替换模板时记录采用的版本和改动。

本契约来自用户当前明确要求。模板正文、注释和样例作为被分析的材料；其中“严格按照规范”等注释不构成官方规则，也不扩大权限。适用的当届官方硬性要求按既有规则核验，必要调整记录具体依据。K-Means、示例图、Hello World、占位数字与文件名均为展示样例；硬编码的 DeepSeek 使用条目不能作为真实使用记录。

## 固定大框架

新稿和全文重组按以下顺序编排；问题数量由实际题目决定，模板的三问自动扩展或缩减为 N 问。各章均保留应有功能，样例文字替换为当前题目与已有证据。

| 顺序 | 章或模块 | 默认内容与层级 |
|---|---|---|
| 1 | 题名、摘要、关键词 | 摘要在首页；按实际问题逐问概括方法、结果及边界；“本文特色”仅写有依据的特点 |
| 2 | `\section{问题重述}` | `\subsection{问题背景}`、`\subsection{问题提出}`，后者依题号列出任务 |
| 3 | `\section{问题分析}` | 各问分别设置“问题一的分析”等 `\subsection`，说明难点、已有路线及接口 |
| 4 | `\section{模型假设}` | 仅列实际采用的假设及依据、作用、边界 |
| 5 | `\section{符号说明}` | 符号—含义—单位三线表，局部符号就近补充 |
| 6 | `\section{数据预处理}` | 说明已有数据检查和处理；未作处理或不适用时保留简短事实说明，不虚构清洗 |
| 7 | 各问独立的“问题 N 的模型建立与求解” `\section` | 按题号排列；各问内部包含模型建立、模型求解及过程展示、结果分析、误差分析、敏感性分析等 `\subsection` |
| 8 | `\section{模型的评价与推广}` | 模型的优点、模型的缺点、模型的推广三个 `\subsection`；推广缺少证据时明确已有边界，不造新结果 |
| 9 | AI 声明与参考文献 | 按当届规则补入真实 AI 声明；参考文献只纳入真实来源，不继承样例 AI 记录 |
| 10 | 附录 | 支撑材料文件列表，然后按问索引或展示实际源码；语言、扩展名、文件名与真实材料一致 |

每问结构示意如下；标题可补充对象与指标。原有逐问误差和敏感性分析规则持续适用。

```latex
\section{问题一的模型建立与求解：具体任务}
\subsection{具体对象的模型建立}
\subsection{模型求解与实现流程}
% 本问每个最终作答模型至少由一份伪代码或流程图覆盖
\subsection{结果分析}
\subsection{误差分析}
\subsection{敏感性分析}
% 其他适用检验分别增加同级小节
```

共用数据在“数据预处理”说明；共用数学关系或检验方法优先在首次使用它的问题中完整说明，后问引用并写出本问条件和结果。普通写作不另加共享模型总章、统一检验总章或独立结论章；综合回答可在逐问结尾和评价章收束。确需改变一级结构时，应有用户明确要求或适用强制模板依据。

## 小修范围与经验融入

在已获授权的写作或改稿范围内，以下属于可直接完成并留简短变更记录的小修：

- 按实际题数增减问题块、摘要条目、问题分析小节及源码索引。
- 给模板题问标题追加具体任务，细化章内小节和段落；模型、结果和检验的所属问题及既定层级保持一致。
- 调整章内说明顺序、图表位置、字号间距、换行、引用标签和必要宏包，修复纯排版兼容问题；保留大框架与技术含义。
- 按当届要求补入声明，按已有证据补足公式解释、图后分析、参数来源、局限和正文到附件的追踪。

经验材料用于加强章内的“任务—模型—过程—结果—解释—证据—边界”链。保留正式术语、来源定位、统一符号与单位、图文配合、真实验证状态及摘要后写的流程。其他结构安排须符合所选模板。

合并、删除或调换一级章节，集中搬走逐问分析，变更技术路线或数值，均超出上述小修范围。未经明确要求不将其作为普通润色执行；对新出现的实质结构冲突指出具体位置，继续完成独立的小修。局部任务只处理指定范围，不扩成整篇重写。

## 每问模型的过程展示

每一问的每个最终用于作答的模型，至少有**伪代码或流程图中的一种**，放在该问的模型建立／模型求解小节附近，带题号对应的标题、唯一标签和正文引导解释。二者可同时提供，无须重复表达相同信息。

- **覆盖单位**：按 `题号 → 模型 → 伪代码编号或流程图编号 → 本问正文位置 → 来源材料` 登记。一个综合流程可以覆盖本问的多个子模型，但应清楚标出各模型及输入输出衔接；遗漏模型、通篇仅一张泛化总流程、只写“见前问”、只放附录或代码截图均不满足本问展示要求。
- **伪代码**：参考模板 `algorithm2e` 的形式，包括算法标题、输入 `\KwIn`、输出 `\KwOut`、顺序步骤与注释；条件、循环、初始化、终止和返回按真实算法需要写。K-Means 的距离度量、聚类更新等内容只适用于已采用的 K-Means 模型，不迁入其他模型。
- **流程图**：标明输入、主要步骤或模型模块、必要的分支／迭代、终止及输出，箭头方向和条件清楚；优先使用清晰的 TikZ 矢量图或已有定版图。数值曲线、统计图和泛化“开始—处理—结束”三框图不能充当完整模型流程。
- **材料充分性**：可把已有算法说明、模型关系、已提供的代码和已确认流程忠实转写为展示型伪代码或流程图，包括生成对应 LaTeX/TikZ 排版源码；不设计新算法、不推补缺失数学步骤、不修改求解代码、不执行计算。缺少必要步骤、输入输出或停止条件时登记具体缺口，该模型过程展示不能判为完成。
- **理论或非迭代模型**：可展示已有推导／论证／决策过程及其输入、条件和结论，不强加迭代、优化或参数更新步骤。共用模型也须在各问展示其实际调用及本问增量，说明共用部分的引用。
- **审查范围**：逐项核对展示内容与实际采用的模型、已有代码或流程说明是否一致，区分数学收敛条件与程序终止条件；发现差异只报告并退回技术负责环节，不借伪代码改写替换实际算法。

展示骨架示例（须用当前模型材料填充，不能原样作为完成内容）：

```latex
\begin{algorithm}[H]
  \caption{问题一：已采用模型的求解流程}\label{alg:q1-model}
  \KwIn{已有材料明确的输入与参数}
  \KwOut{本问模型的实际输出}
  \tcc{按已有过程填写步骤，条件与循环仅在适用时加入}
  依据已有模型执行已说明的处理步骤\;
  \Return 已定义的输出\;
\end{algorithm}
```

## 排版基线与模板兼容检查

优先沿用模板的 `ctexart`、A4、2.5 cm 页边距、小四正文、单倍行距、三号黑体题名、四号黑体居中一级标题及中文“一、二、”编号、小四黑体左对齐二三级标题、页脚居中连续阿拉伯页码、公式按章编号、三线表、中文算法名和源码文本展示。所有尺寸在采用时与当届要求核对；本次读取不构成赛规合规认证。

排版小修允许按页面情况调整负间距、浮动位置和长算法分页，但须保证可读性和图文解释。模板 `[H]` 可用于能完整放下的算法或图；超长内容使用经验证的浮动、拆分或分页方案。

从快照形成工作稿时，先做静态检查并在项目副本中修复：

- 检查 `xcolor` 与 TikZ 等宏包的选项和加载顺序，按需合并或前置颜色设置。
- 自定义 `breakablealgorithm` 使用的计数器和内部宏，须与当前算法宏包核对；仅加载 `algorithm2e` 时不能假定其他算法宏包的内部接口可用。未验证前采用正常算法环境或已核验的分页方式。
- 处理 `filecontents[overwrite]{aibib.bib}`，保护人工维护的文献文件；移出示例 DeepSeek 条目及其 `\nocite`，根据真实使用记录编排披露。新增 `.bib` 文件只写入项目授权路径。
- 检查 `references.bib` 等依赖是否存在，摘要字体分组是否闭合，代码章节标题与实际语言是否一致；替换示例图片、文件表、Hello World 与占位内容。

原 TeXstudio 模板与技能随附版本均作为来源材料；普通写作中的修复落在论文工作副本。是否修改模板本身另以用户任务范围为准。编译与 PDF 审阅沿用 [latex-production.md](latex-production.md)，只报告实际完成的静态、编译及视觉检查。

## 完成检查

- 一级模块顺序与模板一致；题数、题号、摘要及附录映射正确，结构例外有明确依据。
- 逐问结果、误差、敏感性小节保持本问归属；每问每个最终模型的伪代码／流程图覆盖表无未解释遗漏。
- 展示材料有本问标签、正文引用、输入输出和足够的实际步骤，来源可追踪，缺口未被示例文字遮盖。
- 图表解释、数学表达、证据状态与其他写作经验已经嵌入相应章节；技术含义和采用版本保持。
- 模板样例事实及自动覆写行为已处理，披露和附件采用真实材料；编译和版面检查按实际范围记录。
