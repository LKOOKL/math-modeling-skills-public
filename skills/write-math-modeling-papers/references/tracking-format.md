# 决策与证据追踪标记

用于写作、方法解释、求解包和审计之间的来源追踪。标记格式由目标文件决定；实际决策权限、来源和状态另按 [决策授权契约](../../workflow-orchestrator/references/decision-authority.md) 核查。标记存在本身不证明决策已获授权、数值已验证或论文已完成。

## LaTeX 正文

在所追踪段落之前使用**独立一行**的 TeX 注释，下一行开始正文：

```latex
% decision_id: Q1-D03
此处是与该决定及既有证据一致的正文。
```

- 不把 HTML 注释插入 `.tex`；它可能正常编译并印到 PDF。
- 不把 `%` 与需要保留的正文放在同一行，避免注释吞掉正文。
- 同一段有多个来源时，可分别写多条独立注释，或在追踪矩阵逐一映射。
- 外部既有求解材料没有内部决策编号时，使用独立的 `% evidence_id: Q1-E01`，并在材料矩阵登记实际文件、版本、页码或字段；不伪造内部决定。

## Markdown 交接与记录

Markdown 可以使用独立行的 HTML 注释，也可以在显式来源字段或映射表记录编号：

```markdown
<!-- decision_id: Q1-D03 -->
与该记录对应的说明。
```

转写到 LaTeX 时必须转成 TeX 注释或改由外部追踪矩阵承载，不能原样复制 HTML。正文唯一来源仍是 LaTeX，Markdown 只承担交接和审计记录。

## 生产者与审计者的共同检查

1. 生产者登记 `文件 → 段落或标签 → decision_id/evidence_id → 实际来源与版本`；保留真实作者和审核状态。
2. 审计者按文件类型解析注释或矩阵，核对源记录是否存在、适用于当前主张且未失效；不能只匹配一种 HTML 字符串。
3. 在 `.tex` 中搜索 HTML 注释残留，检查独立 `%` 行后仍有应保留的正文。
4. 编译后从 PDF 提取文本，确认内部追踪编号和注释内容没有意外进入正文，并实际检查对应句子仍出现。明确记录测试范围；附录中经授权展示的原始记录可另作例外登记。
