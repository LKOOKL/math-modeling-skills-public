# LaTeX 论文制作与版面审查

## 范围与年度依据

LaTeX 是唯一正文源，优先按 [用户国赛模板契约](user-template-contract.md) 的固定骨架与版式工作，并按当届官方硬性要求调整；其他草稿的有效内容迁入同一项目，不维持 Word 双轨。正文技术内容来自用户材料，本文件只指导写作组织、过程展示转排、编译和 PDF 审查。

- **局部章节任务**：只修改指定章节、相关标签和必要的公共样式；检查受影响引用及页面，说明全文页数与最终匿名检查是否尚未覆盖。
- **全文任务**：建立全篇材料映射，编译完整项目并逐页审阅。
- 当届纸张、页边距、首页、正文目录、页码、页数、匿名和文件大小须在使用时核验。2026 设计基线见 [submission-checklist.md](submission-checklist.md)，个人模板和历年经验不覆盖全国官方规则。

## 写作项目组织

保留可用的用户文件组织；新项目按下列写作职责分文件。文件可合并或拆分，实际一级章节仍遵循模板顺序，题问文件数随实际题数变化：

```text
paper/
├─ main.tex
├─ sections/
│  ├─ abstract.tex
│  ├─ problem_restatement.tex
│  ├─ problem_analysis.tex
│  ├─ assumptions.tex
│  ├─ symbols.tex
│  ├─ data_preprocessing.tex
│  ├─ question1.tex
│  ├─ question2.tex
│  ├─ evaluation.tex
│  └─ ai_statement.tex
├─ figures/                      # 已有定版图，或依据已有流程转排的展示图
├─ tables/                       # 或 data_display/：既有结果的展示稿
├─ bibliography.bib
├─ appendices/
│  ├─ material_index.tex
│  └─ supplied_listings.tex      # 仅索引或原样引入用户源码
└─ build/                        # 仅排版构建产物
```

用户已有代码、数据和结果作为外部材料保留；本项目不建立求解、结果生成或复现执行工作流。表格只忠实转排现有内容；可依据已提供的模型流程编排 algorithm2e 伪代码或 TikZ 流程图，不计算新数据。缺少结果图资源、派生数值或流程本身时登记具体缺口。

1. 以“题问—主张—证据—正文位置”材料矩阵安排章节文件，明确每问直接答案和共享材料的引用位置。
2. 由主文件统一导入摘要、前置章节、逐问主体及收尾；每问文件定义本问 `\section`，结果、误差、敏感性等分析分别使用其下的 `\subsection`。可拆为片段再由本问文件 `\input`，归属按实际展开层级核验；不另起统一检验总章。先完成有材料支撑的正文，再完成摘要。
   每问每个最终模型的伪代码／流程图置于本问建立或求解小节，逐一核对覆盖、来源、编号、标签、正文引用和解释。模板 K-Means 仅提供排版形式，逻辑内容按实际模型转写。
3. 假设、符号和公式保留用户采用版本；原稿解释不足时标记具体缺口，不补推导。
4. 文献条目集中管理，正文引用键与条目双向对应；人工维护的文献文件禁止被构建步骤覆盖。
5. AI 声明和附录单独组织，位置服从当届规定。细则见 [ai-writing-and-disclosure.md](ai-writing-and-disclosure.md) 与 [appendix-and-supporting-materials.md](appendix-and-supporting-materials.md)。

## 标题、公式与交叉引用

标题按 [heading-naming.md](heading-naming.md) 同时提供题问范围与实质内容。优先保留已有稳定标签，新增标签采用“类型前缀＋范围＋语义”，如 `sec:q1-results`、`eq:q1-objective`、`fig:q2-comparison`、`tab:q1-answer`；所有名称均来自用户材料。

- 用层级命令产生编号，不手写章节号；标题以文字为主，书签需要时使用 `\texorpdfstring{显示标题}{纯文本书签}`。
- 公式前交代目的和关系，公式后解释符号、条件与含义；所缺技术解释列为待提供。
- 图表遵循“正文引入目的 → 图表及标题 → 正文解读”，`\label` 紧随 `\caption`，正文使用交叉引用。
- 精确值优先用表，趋势或差异使用用户已有合适图件。结果图表解释读数与题目意义；符号表、材料清单等描述型表按用途解释，无须强加趋势段。
- 检查公式、图、表、算法说明及附录的编号、单位、对象、引用目标与来源版本。

## 浮动体与页面信息

页面尽量图文配合，必要定义、用户已有推导或讨论允许纯文本页；禁止整页只有缺乏正文解读的图表。图表集中或过大时优先拆分信息、调整相邻正文和浮动位置，避免孤立图表、孤立标题及大面积无效留白。

浮动位置优先使用 `[htbp]`，根据现有版式谨慎设置章节屏障；固定位置仅用于明确的排版需要。保留可读字号、足够行距、坐标单位、图例与灰度辨识度，不用过度缩小字号、图形或页边距解决拥挤。排版调整不得改变用户数据、图形含义或结果精度。

使用 algorithm2e 的 `[H]` 环境时，先以空行或 `\par` 结束前面的引导段落，再开始算法；检查它没有嵌入未结束段落而向右挤出页面。编译退出码为零仍需查看算法整页。

## 模板审查与纯排版编译

优先采用用户已有编译引擎、类文件和最小宏包集合。按 [模板兼容检查](user-template-contract.md#排版基线与模板兼容检查) 在论文副本中核对颜色宏包加载顺序、algorithm2e 与跨页环境接口、摘要字体作用域、文献依赖、语言与扩展名、附录编号、页码和元数据。处理 `filecontents[overwrite]` 保护既有文献库，移出样例 DeepSeek 条目并按真实记录披露；原样快照不作为可直接编译的成品。

编译前读取实际构建命令及相关配置，确认只做 TeX 排版和文献处理；检查外部命令、自动绘图、脚本钩子和 shell escape。若任何步骤会触发求解、数据处理、绘图再计算或用户代码运行，停止该步骤并报告“触发入口—作用—所缺预生成材料”；可继续独立章节写作或安全的排版步骤。不得以“构建依赖”为由执行技术计算。

每次构建使用新的隔离运行目录，保留上次成功 PDF、日志及源稿。先把本次实际排版所需源码和依赖复制到隔离工作副本并记录来源；不在交付目录运行清理，不自动删除旧产物。输出目录使用单独的 `out/`，路径兼容性有疑问时用 ASCII 运行目录名。完整安全步骤见 [paper-compile](../../paper-compile/SKILL.md)。

已确认纯排版且项目采用 XeLaTeX/Biber 时，在隔离工作副本中使用以下参数化链或已审查的项目等价配置；引擎、入口和文献工具以实际项目为准，无文献工具依赖时省略相应步骤：

```text
xelatex -no-shell-escape -interaction=nonstopmode -halt-on-error -output-directory=out main.tex
biber --input-directory=out --output-directory=out main
xelatex -no-shell-escape -interaction=nonstopmode -halt-on-error -output-directory=out main.tex
xelatex -no-shell-escape -interaction=nonstopmode -halt-on-error -output-directory=out main.tex
```

可调用环境可用的 LaTeX 编译能力，不硬依赖特定工具名。只修复 TeX 语法、资源路径、交叉引用、缺字、字体、溢出和浮动布局等问题；数学含义、结果、源码或数据缺口退回用户。需要 shell escape 的既有排版组件先核对实际外部命令与权限；无法确认其只用于排版时保持停用并报告，不默认开启任意外部执行。

编译记录包含入口、引擎、实际命令、成功或失败、日志位置和未解决警告；失败时保留隔离目录及旧交付 PDF，旧稿仍标记其原版本，不冒充本次构建结果。仅在新 PDF 可解析且完成本次范围所需检查后交付为新版本；不自动覆盖旧版本。重复编译仅用于新增修改或尚未解决的引用等问题。依赖或字体缺失时说明具体限制，安装及系统配置调整另按授权边界处理。

## PDF 审查与交付

全文任务逐页核对，局部任务注明实际检查页：

- 摘要首页及起始页码、连续页码；正文目录是否符合当届禁令，PDF 书签与正文目录分别检查。
- 公式、图表及其解释完整，无裁切、重叠、缺字、错误单位和不可读小字；引用无未定义或错误跳转。
- 标题层级、书签编码与目标、孤行、孤立标题、留白和浮动体位置合理；页面信息规则得到满足。
- 首页、正文、附录、文件属性、图像和链接中的匿名信息符合当届规则；页数和文件大小按当届具体限值核对。
- PDF 必须可解析并包含预期页面和内容；不设置“超过 100 KB”一类最低体积门槛。正文边界按当届定义和实际标签／页面定位，不依赖独立 Conclusion 章存在。按 [追踪标记约定](tracking-format.md) 核对 TeX 独立注释行、PDF 隐藏编号及相邻正文保留。
- 摘要、正文、图表和附件采用同一材料版本；源码引入只核对展示及索引，不据此声称运行成功。

交付 `.tex` 及实际生成的 PDF，列出已检查范围、编译状态、规则来源和未关闭问题；未取得或未审阅的 PDF 明确标记“未完成版面核验”。技术正确性与可运行性依用户提供的证据及确认记录说明。
