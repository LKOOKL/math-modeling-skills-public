# 数学建模论文章节标题命名

## 目的与使用范围

标题让读者知道当前内容属于哪一问、讨论什么对象、承担什么功能。命名只提取用户已经确认的任务、对象、模型、步骤或结果表达；标题编辑不选择方法、不发明模型名或创新名称，也不补充正文没有的技术事实。

先按 [用户国赛模板契约](user-template-contract.md) 固定一级框架，再按 [chapter-workflow.md](chapter-workflow.md) 组织章内内容。每问为 `\section`，结果、误差、敏感性等分析分别为本问 `\subsection`；每问模型还须有伪代码或流程图展示。本文件的路径模板用于章内细化和已明确的结构例外，不自动改变模板骨架，不输出正文目录。

## 主规则：范围锚点＋语义锚点

逐问主体的标题路径应提供以下两类定位信息；模板固定导航标题可保留原名，具体对象与方法在下级标题或相邻首段补足：

- **范围锚点**：问题编号、共享范围或已存在的论证阶段。
- **语义锚点**：用户已确认的研究对象、模型、关键关系、步骤、任务或输出。

固定导航标题包括“摘要、问题重述、问题分析、模型假设、符号说明、数据预处理、模型的评价与推广、参考文献、附录”，以及模板的“问题 N 的模型建立与求解”和按规则设置的 AI 声明；保持稳定名称并与正文内容对应，可在题问标题后追加具体任务。

两个锚点可以分布在父子标题中；固定模板导航路径也可由相邻首段补足语义。题问父标题保留“问题 N 的模型建立与求解”，可追加已有任务名称；下级标题按对象和功能细化。同一问题的“模型求解”附近放置带题号标签的伪代码或流程图，并由正文解释实际步骤。采用独立语义任务章须先满足模板契约中的显式结构例外。

“建立与求解”只作为导航型标题，不据此声称发生了模型创新。具体技术名称全部来自用户材料；多个方法并列出现并不自动代表融合模型。带“最优、显著、高精度、稳健”等性质的标题需要用户已有充分证据及适用范围，正文中的完整结论通常留在结果段。

## 标题命名算法

1. 先区分固定导航标题与逐问主体／共享技术章节；固定导航标题核对名称与正文功能后转第 5 步，技术章节继续标出服务的题问／共享范围及具体功能。
2. 从对应正文和用户确认材料提取一个语义锚点，同时保留材料位置供核对。
3. 保留模板一级标题及顺序，在题问标题追加任务或在下级标题／首段补足语义；逐条检查路径能定位题问和具体内容。
4. 采用“对象＋功能”“问题 N：任务／输出”或“基于已确认方法的任务”等简洁结构；只保留本节真正展开的内容。
5. 同级标题使用平行语法与相近粒度，压缩重复对象和方法堆砌。
6. 返回正文核查标题覆盖范围，随后检查内部章节提纲、章节编号、引用标签、附件名与 PDF 书签；不生成正文目录。

资料不足以支持具体命名时使用题号与任务导航名称，并询问缺失的对象或正式术语；不临时命名技术方法。下列模板中的槽位必须由用户材料替换，未能替换的槽位不得进入定稿。

## 不同结构的标题路径模板

### 逐问闭环

适用于各问对象或任务有明显区别的现有方案。

```text
问题一的模型建立与求解：〈用户确认的对象与任务〉
  〈对象〉的模型表达
  〈用户确认的方法〉求解过程
  〈核心输出〉的结果分析
  〈本问输出〉的误差分析
  〈本问参数〉的敏感性分析
问题二的模型建立与求解：〈用户确认的对象与任务〉
```

每问标题为 `\section`，上述结果、误差、敏感性标题分别为本问的 `\subsection`；轻量分析保留简短小节。其他适用检验同级单列，缺失与不适用项按 [逐问结果分析的层级与归属](chapter-workflow.md#逐问结果分析的层级与归属) 记录。首次完整答案放在相应结果节；标题仅提示输出主题。

### 模板内共享基础材料＋逐问扩展

适用于至少两问实际复用同一组材料。

```text
数据预处理
  〈共享数据〉的已有处理
问题一的模型建立与求解：〈任务〉
  〈首次使用的共同关系〉的表达
  共享内容的引用与本问条件
  〈本问输出〉及结果分析
  〈本问输出〉的误差分析
  〈本问参数〉的敏感性分析
问题二的模型建立与求解：〈任务〉
```

“数据处理”“机理”“基础模型”等名称只在用户确实提供对应内容时采用；共用数据归于数据预处理，共同数学关系放在首次使用的问题中，各问开头交代继承项和新增项。共用检验方法可引用，各问仍分别保留结果、误差、敏感性分析小节及模型过程展示。

### 依赖链／语义任务序列

适用于用户方案已有明确的信息传递关系。

```text
问题一的模型建立与求解：〈第一阶段任务〉
  〈第一阶段输出〉及结果说明
  〈第一阶段输出〉的误差分析
  〈第一阶段参数〉的敏感性分析
问题二的模型建立与求解：〈使用前问输出的第二阶段任务〉
  输入承接与适用条件
  〈第二阶段输出〉及结果说明
  〈第二阶段输出〉的误差分析
  〈第二阶段参数〉的敏感性分析
```

阶段名称从真实任务提取，作为模板题问标题的补充或小节内容；一级标题保持题号顺序和“模型建立与求解”结构。每问保持 `\section`，结果、误差、敏感性分析分别为 `\subsection`。正文写清具体传递量与使用位置，不为了标题递进制造技术依赖。

### 总章分问（仅显式格式例外）

仅在用户另有明确层级要求或强制模板规定时使用，并记录要求来源；通常采用前述每问 `\section` 的结构。

```text
模型建立与求解
  问题一：〈对象与任务〉
    〈已有模型／求解功能〉
    〈输出〉及结果分析
    〈输出〉的误差分析
    〈参数〉的敏感性分析
  问题二：〈对象与任务〉
    〈已有模型／求解功能〉
    〈输出〉及结果分析
    〈输出〉的误差分析
    〈参数〉的敏感性分析
```

保持问题与对应分析的父子归属；即使采用显式格式例外，各问误差、敏感性等分析仍分别设独立子标题，不能集中到跨问检验总章。

### 前置与收尾导航

沿用模板的前置与收尾导航；共用检验方法放在首次使用的问题中，各问保留对应结果分析。独立结论章仅按明确要求增设，AI 声明按当届规则安排。模板“模型的推广”小节依据已有材料说明适用范围；缺少推广证据时明确边界，不将标题写成已验证的普适性主张。

## 功能标题取词

| 已有内容功能 | 可用标题形式 | 核对重点 |
|---|---|---|
| 任务分析 | `问题 N 分析`；`〈对象〉的〈难点〉分析` | 正文解释用户已采用的路线 |
| 数据处理说明 | `〈数据对象〉的预处理说明` | 步骤、理由和影响已有材料支持 |
| 参数与条件 | `〈参数〉的来源与取值`；`本问条件说明` | 参数、范围和条件来自用户资料 |
| 模型表达 | `〈对象／关系〉的模型表达` | 模型名、公式与正文一致 |
| 优化结构 | `决策变量`；`目标函数`；`约束条件` | 父标题已提供问题与对象 |
| 求解叙述 | `〈用户方法〉的求解过程`；`求解输入与步骤` | 已完成步骤和输出可定位 |
| 结果回答 | `〈核心输出〉及结果分析`；`〈已有比较对象〉的结果比较` | 标题范围与实际结果覆盖相符 |
| 检验说明 | `〈输出〉的〈已有指标〉检验`；`〈参数〉的敏感性分析` | 对应检验及结果已由用户提供 |

表中的通用功能名称用于技术章节时，只在父标题已提供题问范围与事实性对象／任务时使用；其余技术路径须把用户已确认的对象或任务补入下级标题。算法步骤可用“步骤 N：〈用户已有动作与对象〉”作为段落引导语。附件索引采用用户实际文件名；章节可有中文说明性标题，但不得让读者误以为存在另一个文件或入口。

## 长度、层级与 LaTeX 标识

- 默认控制在两至三级标题；第四级信息优先使用段落引导语或编号说明。
- 导航标题保持简短；正文子标题可参考 6—12 字，含必要具体术语时适当延长。语义化逐问标题可参考 12—24 字，长度不是硬阈值。
- 同一标题同时塞入对象、多个方法、目的及完整结论时，保留核心主题，把其余信息移入正文。
- 使用文稿模板既有编号体系，保证唯一、连续、层级一致；不强行替换用户已确认的编号风格。
- LaTeX 每问使用 `\section`，结果分析、误差分析、敏感性分析等分别使用该问题下的 `\subsection`；已有 `\label` 优先保持稳定，新增标签可按 `sec:q1-results`、`sec:q1-error`、`sec:q1-sensitivity` 命名，确保唯一并与 `\ref` 对应。仅显式格式例外可调整这一层级。
- 标题以文字为主，引用标记、脚注和复杂公式放入正文。确需数学符号时用 `\texorpdfstring{显示标题}{简洁书签标题}` 提供可读书签。
- 按 [latex-production.md](latex-production.md) 执行纯排版编译，审阅用户提供或本次编译得到的 PDF 章节标题与书签，检查换行、乱码、层级跳跃、孤立标题和截断；不输出正文目录，纯排版编译不运行技术计算代码。仍未取得可审阅 PDF 时如实记录未核验，不声称完成版面审阅。
- 标题、图表、摘要、附件索引中的对象和方法名称统一；附录名称与实际附件名保持对应。

## 常见失效与审查清单

| 失效信号 | 修订方向 |
|---|---|
| 逐问主体或共享技术章节的父子标题都是“模型建立／求解／分析” | 在该技术路径中补入用户已确认的对象或任务，固定导航标题按其例外规则审查 |
| 多种方法名连续堆砌 | 提取本节核心主题，把已有技术组合细节放入正文 |
| 标题塞入数值和完整结论 | 保留输出主题，直接答案放结果段 |
| 标题写“优化”，正文只报告预测；或标题承诺比较而无比较结果 | 按正文实际功能改名，技术缺口向用户核问 |
| 同级一项为方法、一项为大问题、一项为单个公式 | 调整为相近范围与粒度 |
| “高精度、最优、创新”等修饰缺少证据 | 使用事实性主题，记录待确认主张 |
| 题号映射缺失、父子重复、编号跳跃、槽位未替换 | 修复导航和编号，保留统一术语 |

逐项标记“通过／待修改／待确认／不适用”：

- [ ] 每个题问能从内部章节提纲定位到相应主体和结果答案。
- [ ] 实际 LaTeX 中每问 `\section` 下分别存在结果、误差、敏感性等 `\subsection`，对应结果与解释留在本问；共享方法引用未替代局部分析，缺失或不适用项有具体说明。
- [ ] 模板一级顺序和固定导航名称保持；各题问路径的具体对象／方法可从标题或相邻首段定位，结构例外有明确依据。
- [ ] 固定导航标题按显式例外保留稳定名称，标题与正文功能对应。
- [ ] 结构与用户已提供的共享范围、依赖关系一致。
- [ ] 模型名、方法名、步骤和性质主张均有用户材料依据。
- [ ] 标题承诺与正文实际覆盖一致，同级语法和粒度平行。
- [ ] 章节标题保持两至三级为主，编号、标签和交叉引用对应；未输出正文目录。
- [ ] 标题、图表、摘要与附件名的术语一致。
- [ ] 内部章节提纲、章节标题、标签及可用的 PDF 书签已审阅；未取得的版面材料明确列为未核验。
